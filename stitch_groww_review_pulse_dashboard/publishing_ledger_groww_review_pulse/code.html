Why the Ledger Matters

The ledger guarantees strict idempotent behavior. Without these verification hashes, automated retries could append multiple conflicting weekly review sections into the executive master Google Doc or spam stakeholders with duplicate Gmail draft notifications.

Recovering a Partial Run

If a run encountered network latency during execution (like 2026-W41), use the CLI resume flag. The engine skips already finalized Google Doc sections and picks up directly at the interrupted draft step:

python -m pulse run --resume <run_id>
